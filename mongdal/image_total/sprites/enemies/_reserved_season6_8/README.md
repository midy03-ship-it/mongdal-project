# 시즌6~8 엘리트 몬스터 예약 이미지

원본: `이미지 모음/00. 종합 안쓴거/몬스터, 보스 안쓴거/`
(2026-07-24 배정, 시즌2~4 엘리트 버그 수정과 함께 정리)

시즌6/7/8이 실제로 만들어지면:
1. 이 폴더의 파일들을 `mongdal/image_total/sprites/enemies/`로 옮기고 (파일명은 그대로 `elite_chXX_YY.png` 이미 챕터쌍 규칙에 맞게 지어둠 — 실제 챕터 번호가 51~80이 아니면 파일명만 맞게 다시 바꿀 것)
2. `mongdal/js/data/monsters.js`의 `MONSTERS.elites`에 데이터 추가 (시즌2~4 추가할 때 쓴 패턴 참고: hp/damage/xp/gold를 그 시즌 일반 몬스터 체력의 약 3배/1.5배/hp÷9로 계산)
3. `mongdal/js/data/sprite-config.js`의 `enemies` 섹션에 `__MON_elite_chXX_YY__` 플레이스홀더 등록
4. `mongdal/js/systems/spawner.js`의 엘리트 선택 삼항연산자 체인에 챕터 분기 추가

## 배정 내역
- **시즌6 (예상 챕터51~60)**: `ss4 boss 30001~30005` + 보너스(`mon_ex10006`, 초록뿔도깨비)
- **시즌7 (예상 챕터61~70)**: `ss4 boss 30006~30010` + 보너스(`mon_ex20006`, 초록배불뚝이오니)
- **시즌8 (예상 챕터71~80)**: `ss5 boss-30003/30004/30005/50001/50003` + 보너스(`mon_ex30006`, 우주촉수눈신)

이미지들이 원래 "보스급" 그림체라 엘리트치고 화려한 편 — 시즌6~8 만들 때 실제 보스와 안 겹치는지 한 번 더 확인할 것.
